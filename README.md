# Cognifyz-Beginner
Level 1 - Task 1: HTML Structure and Basic Server Interaction

Cognifyz Technologies – Full Stack Development Internship

This repository contains my implementation of Level 1 – Beginner Task 1 as part of the Cognifyz Technologies Full Stack Development Internship.

Intern Name: Srimanthula Sukanya

Objective

To understand HTML form structures, basic server interaction, form submissions, and server-side rendering using Node.js, Express.js, and EJS.

Task Steps Implemented

1. Created an HTML form to collect user details (Name and Email).
2. Set up a Node.js server using Express.js.
3. Created server-side routes:
   - "GET /" – Displays the registration form.
   - "POST /submit" – Handles submitted form data.
4. Used EJS (Embedded JavaScript) to dynamically render the submitted data.
5. Displayed the submitted Name, Email, and server timestamp on the result page.

Project Demo

The application allows users to enter their Name and Email. After submitting the form, the server processes the information and displays the submitted details using EJS server-side rendering.

Example Output:

- Name: Srimanthula Sukanya
- Email: sukanya@gmail.com
- Time: Server Timestamp

How to Run Locally

Step 1: Clone the repository

git clone https://github.com/srimanthulachandramouli0/cognifyz-level1-task1.git

Step 2: Navigate to the project folder

cd cognifyz-level1-task1

Step 3: Install dependencies

npm install

Step 4: Start the server

node server.js

Step 5: Open in your browser

http://localhost:3000
